Optimal parameters of each tectonic block
========================================
The program optimizes directly against the reference Curie depths Zb(km); heat flow is not recomputed.
The spectral fitting bands are real wavenumber ranges (km^-1), not integer indices.
The uncertainty dZb is not part of the optimization: it is computed afterwards over the full map and used only for the independent assessment of the model.
